# Photos à prendre — scopes/défibrillateurs (module Suivi du matériel)

Ces photos servent à l'écran de choix de la configuration : l'utilisateur
reconnaît le scope sur la photo et le sélectionne.

## Rappel du fonctionnement

- **LP15** et **Schiller T7** : tous identiques, pas de configuration à choisir.
- **Tempus Pro** (scope) + **Tempus LS** (défibrillateur) : forment ensemble un
  scope/défibrillateur. 4 configurations : US, UK, standard, hélico.
  La housse et le rangement changent selon la configuration.
- Le choix se fait sur le **Tempus Pro** ; la configuration du **Tempus LS en
  découle** (pas de choix séparé).

## Conseils de prise de vue

- Même endroit, même fond, même éclairage pour les 4 configurations, afin que
  les vignettes soient comparables.
- Cadrer l'appareil entier, de face, sans reflet sur l'écran.
- Les photos pourront être détourées dans l'appli.
